# Global Claude Code Rules

These rules apply to every project on this PC, regardless of what the project is.

## Core Behavior
- Work one small step at a time. Wait for explicit confirmation before continuing to the next step.
- Before any non-trivial or risky action, explain: WHY (reason), WHAT (exact change), RISK (what could go wrong), and HOW TO VERIFY (how to confirm it worked).
- Never overwrite, delete, or modify important files without explicit approval first.
- Ask before running risky or destructive operations (deletions, force-pushes, resets, overwrites, etc.).
- Don't read, inspect, or run commands on files/paths outside the current project folder without asking permission first.
